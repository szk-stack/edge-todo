# PRD — 极简待办（三端云同步）

- 版本：v0.1（MVP 基准）
- 日期：2026-09-07
- 状态：待评审

---

## 1. 产品概述

**一句话定位**：随手记、随手看、随手勾的极简待办 —— 网页端完整管理，Windows 端贴边速记，安卓端桌面组件速览。

**核心价值**：
- 快：记录和查看的路径极短（桌面端鼠标一划即出，手机桌面组件直达）
- 轻：无清单套娃、无复杂属性，打开即用
- 通：三端数据实时同步，离线可用

**目标用户**：个人效率用户，记录生活/工作中的琐事与任务，拒绝重型 GTD 工具。

## 2. 产品原则（边界声明）

| 做 | 不做（Non-goals） |
|---|---|
| 任务增删改、勾选、排序 | 多人协作、分享清单 |
| 回收站（软删除） | 附件、图片、富文本 |
| 简单提醒（P1） | 日历视图、看板视图 |
| 清单分组（P1，单层） | 子任务多级嵌套、标签体系 |
| 桌面组件、贴边弹出 | 番茄钟、习惯打卡等周边功能 |

> 原则：任何让"记一条任务"超过 2 秒的功能都不进 MVP。

## 3. 功能需求

### 3.1 MVP（P0）

| 编号 | 功能 | 验收标准 |
|---|---|---|
| F-01 | 新建任务 | 输入框常驻底部/顶部，回车即存，支持连续录入 |
| F-02 | 勾选完成 | 点击勾选框，200ms 内完成动画并移入"已完成"区 |
| F-03 | 编辑任务 | 点击任务标题进入行内编辑，回车/Esc 保存/取消 |
| F-04 | 删除任务 | 左滑/右键菜单删除，进入回收站（软删除，30 天可恢复） |
| F-05 | 拖拽排序 | 长按拖拽，松手即生效；顺序三端一致 |
| F-06 | 已完成区 | 当日已完成折叠展示，可取消勾选恢复 |
| F-07 | 云同步 | 任一端的变更，在线状态下 3 秒内出现在其他端 |
| F-08 | 离线可用 | 断网可正常增删改，联网后自动同步，不丢数据 |
| F-09 | 账号体系 | 邮箱验证码登录，免注册流程（首次登录即注册） |

## 4. 各端需求详述

### 4.1 网页端（功能主战场）

- PWA：可安装到桌面/手机主屏，离线可打开，独立窗口运行
- 响应式：适配 360px 手机宽度到 4K 桌面
- 快捷键：Enter 新建、↑↓ 导航、Space 勾选、Ctrl+Z 撤销
- 深色/浅色主题跟随系统

### 4.2 Windows 桌面端（贴边弹出）

**核心交互规格**：

| 状态 | 行为 |
|---|---|
| 收起态 | 屏幕右缘贴一条 4px 宽、高度约屏高 60% 居中的半透明触发条 |
| 触发 | 鼠标触及屏幕最右缘（x ≥ 屏宽 − 2px）触发区，300ms 确认后滑出（防误触） |
| 展开态 | 宽 320px，高 80% 屏高，右侧贴齐，左侧圆角，置顶显示 |
| 滑出动画 | 200ms ease-out，窗口整体位移（非透明度渐显） |
| 收起 | 鼠标离开窗口且窗口失焦，延迟 500ms 收起；Esc 立即收起 |
| 抑制 | 检测到前台为全屏应用（游戏/视频）时不触发 |

**系统能力**：
- 开机自启动（默认开，可关）
- 系统托盘图标：右键菜单 = 打开面板 / 暂停贴边 / 设置 / 退出
- 多显示器：跟随主屏右缘，可在设置中指定屏幕
- DPI 缩放：100%–200% 缩放下触发条与动画位置正确

**功能范围**：完整任务列表 + 新建 + 勾选 + 编辑；设置页可跳网页端。

### 4.3 安卓端（App + 桌面组件）

**App**：完整功能（同网页端），Material You 风格，支持动态取色。

**桌面组件（标准 AppWidget）**：

| 规格 | 说明 |
|---|---|
| 尺寸 | 4×2（显示约 4 条）、4×4（约 8 条），支持缩放 |
| 内容 | 未完成任务列表（滚动），每行 = 勾选框 + 标题 |
| 交互 | 点勾选框直接完成（无需进 App）；点任务标题进 App 对应任务 |
| 顶部栏 | 组件标题 + "＋"按钮（跳 App 并自动聚焦输入框） |
| 刷新 | 任务变更即时刷新；同步完成后刷新；系统 30 分钟兜底刷新 |
| 主题 | 适配深色模式与系统字体缩放 |

**小米/澎湃OS 适配**（不开发专属组件，仅兼容性处理）：
- 首次添加组件时，引导开启"自启动"与"无限制省电"（否则后台同步会被冻结）
- 小米桌面实机回归测试：圆角、深色模式、字体缩放下的显示
- 上架小米小部件中心：远期可选项，不进里程碑

## 5. 核心用户场景

1. **电脑前想起一件事** → 鼠标划到屏幕右缘 → 面板滑出 → 输入回车 → 鼠标离开自动收起（全程 < 5 秒，不离开当前工作窗口）
2. **通勤路上** → 不解锁手机，桌面组件直接勾掉已完成的任务
3. **换设备** → 手机上记的任务，打开电脑网页端已在列表顶部
4. **断网场景** → 地铁里勾选 3 条任务，出站联网后自动同步，无冲突提示打扰

## 6. 非功能需求

| 类别 | 指标 |
|---|---|
| 性能 | Web 端首屏 < 2s（4G）；桌面端冷启动 < 1.5s，常驻内存 < 100MB；同步延迟（在线）< 3s |
| 可用性 | 全端离线可用；服务不可用时本地功能不受任何影响 |
| 数据安全 | 传输 HTTPS；服务端数据加密存储；提供账号注销与数据删除 |
| 兼容性 | Web：Chrome/Edge/Safari 近两个大版本；Windows 10 1809+；Android 9+ |

## 7. 边界与异常场景

| 场景 | 期望行为 |
|---|---|
| 两端同时编辑同一任务 | 后写入者生效（LWW），静默合并，不打扰用户 |
| 一端删除、另一端编辑 | 删除生效（tombstone 优先） |
| Token 过期 | 静默刷新；刷新失败则保留本地数据，引导重新登录 |
| 同步失败重试 | 指数退避，最多 5 次后挂起，待网络恢复自动续传 |
| 时钟不准的设备 | 同步依赖服务端序列号，不依赖客户端时钟 |
